# Segurança MCP

- Listener numérico 127.0.0.1 com porta dinâmica; MCP desligado por padrão. `Host` precisa ser 127.0.0.1; origens de navegador são rejeitadas. Headers forwarded não são confiados. Não há CORS aberto.
- Token aleatório de 256 bits, efêmero e renovado ao fechar o Studio, comparação em tempo constante. Só sai pelo pipe privado para a UI; config copiada usa variável de ambiente. O botão separado Copiar token é uma ação explícita do usuário. Não há token nos exemplos/logs/URLs.
- Capacidades remotas efetivas: leitura, drafts, preview e exportação como bytes. O cliente pode solicitar aprovação. Apenas a UI pelo pipe privado pode aplicar; Save/Compile e destruição não são ferramentas MCP. Não há shell, arquivos arbitrários, launch de processos ou leitura de credenciais expostos pelo protocolo.
- Cada draft vincula projeto, revisão e ID. A revisão de documento protege contra duas IAs/edição manual simultânea; a revisão de projeto é verificada novamente no adaptador antes da inserção.
- HTTP limitado a 3 MiB, 16 conexões, rate limit de 30 requests/s com burst de 60. Ponte com 16 requests concorrentes, linhas de até 4 MiB e timeout. Limites adicionais estão em MCP_ARCHITECTURE.md. Um processo é exclusivo de uma instância AIR.
- Consultas de objeto retornam no máximo 4.096 referências, com contagem e aviso de truncamento; slots individuais continuam consultáveis. Imports remotos são base64, nunca paths. Exports remotos retornam bytes; gravação local só por file picker humano. Pacote moderno temporário valida diretório exato, nome aleatório, links/reparse points, SHA-256 e 2 MiB; não amplia o limite JSONL do helper.
- Nomes, prompts e pixels são dados. O contrato do provider não altera permissões. Provider HTTPS exige configuração no ambiente e consentimento explícito na UI; redirects desativados.
- Stable Diffusion tem adaptador próprio: somente origem numérica de loopback, configurada pela UI privada. HTTP local permitido explicitamente, sem DNS/proxy/redirects/credenciais no URL. MCP não escolhe endpoint/modelo/scripts/workflows. Basic auth opcional vem apenas de NEXA_SD_USERNAME/NEXA_SD_PASSWORD. Uma imagem, eixo maior 512, resposta HTTP ≤8 MiB e PNG ≤2 MiB; prazo de 180 s. Cancelar descarta o resultado local, sem interromper outros trabalhos no servidor. Detalhes em STABLE_DIFFUSION.md.
- Fechar a janela Studio pausa MCP, revoga consentimento de IA e gira o token; drafts ficam em memória. Para reconectar, reabra, ative MCP e copie o novo token. Trocar/fechar o projeto encerra o gateway e invalida a sessão; a UI exige exportar/descartar drafts antes de sair. Desconectar um cliente HTTP não remove imediatamente seus drafts, pois são compartilhados com o usuário; o limite de quatro e o botão Descartar impedem acúmulo ilimitado. As últimas 100 ações/resultados/timestamps ficam em auditoria de memória; nomes de métodos e estado aparecem na interface, sem prompts, tokens ou bytes. Não há arquivo de auditoria persistente nesta versão.

Limites reais: não é isolamento contra malware no mesmo usuário Windows, administradores ou um processo que leia a memória/clipboard da conta. Não há OAuth, identidades individuais por cliente, permissões administrativas configuráveis ou garantia de cancelamento após uma inserção já executada pelo worker. Em timeout, atualize o projeto antes de qualquer nova aplicação. O helper guarda IDs de commits bem-sucedidos para recusar duplicação por retry na mesma sessão.
