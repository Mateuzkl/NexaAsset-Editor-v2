# Reliability and Resource-Lifetime Audit — 2026-10-14

## Scope and method

Baseline: `f4af80d`, branch `feat/modern-appearances-import`. Review findings were
treated as hypotheses, checked against current source, and changed only where
still valid. All supplied findings applied; none were silently accepted from
review text or skipped as stale. The source inventory contains 358 files under
`src`; the native helper and tests were reviewed separately. This is a risk-based
review of the complete integration and its legacy boundaries, not a formal proof
that every execution path in inherited code or third-party runtimes is safe.

Coverage includes native open/probe, main project transitions, dirty/save state,
conversion, worker settings, mutation queues, sprite/preview ownership, callback
generations, native process/IPC cleanup, helper caches, import/export, publication,
backup recovery, and the existing legacy storage/worker/UI regression suites.

## Verified review findings

| Finding | Resolution and evidence |
| --- | --- |
| Synchronous opening error erased | Clear earlier state before opening; retain the caught message and clear the version label/probe. Main-window regression uses a missing helper and checks the visible error and disabled Load. |
| Legacy conversion falsely marks modern document saved | Conversion completion only refreshes the Save controls. Native Save/Save As remain the only persistence acknowledgment; regression checks the actual registered conversion-completion handler. |
| Native session swallows worker settings | Forward SettingsCommand while continuing to reject legacy asset mutations. Native harness sends settings, then exercises the unchanged legacy worker import path. |
| Open/New discard modern edits or active jobs | Shared project-switch guard checks unsaved/editor changes, helper jobs and saving before clear. Actual New and legacy Open confirmation paths are tested, along with a busy native switch. |
| Per-sprite clearing partially fills queue | One prevalidated atomic helper batch, bounded to 100 distinct IDs; capacity guard includes the three follow-up view jobs. Tests reject oversized/full-queue selections and invalid batch dependencies without changing earlier sprites/revision. |
| Outfit previews include color-mask layer | Base-layer-only composition for outfit thumbnails, default frames and selected-frame PNG export. Explicit mask-layer inspection and all-layer composition for other categories remain available. |
| Nested PowerShell commands ignore exit status | Check LASTEXITCODE immediately after helper build and native runner; the combined UI pipeline passed. |
| JDK selection assumes one installation | Validate exactly one JDK before indexing it. Missing or ambiguous setups stop with a clear message. |
| Oversized stdin line terminates helper | Drain the entire line using a bounded UTF-8 byte budget, emit REQUEST_TOO_LARGE, and continue. Actual helper-loop tests send oversized ASCII and Unicode requests followed by a valid request. |
| Saved generations accumulate | Keep three newest writer backups after commit validation. Protect every current/retained resource; only prune root-local writer-format payloads whose SHA-256 matches the filename. Recovery, malformed metadata, unverified files and unrelated resources are tested. |

## Additional confirmed fixes

- Retired AS pages/data previously used separate delayed disposal closures. A
  single tracked timer now disposes the retirement list; closing cancels it and
  releases retired/current pages, selected data, requests and inventory. Closed
  sources reject new enqueues, and callbacks cannot reattach pages after close.
- Failed pixel-packet parsing now clears already allocated ByteArrays before
  propagating the error; FileStream remains closed in finally.
- Project reset clears the hidden legacy object-clipboard reference when its UI
  flag is disabled. Native Copy snapshots only the record bytes instead of
  retaining an entire original protobuf buffer through a ReadOnlyMemory slice.
- Save As cannot close during publication; unrelated preview errors do not make
  it appear idle. Explicit project teardown shuts it down before closing.
- A final progress/notification error cannot roll back a generation after the
  validated model/cache baseline has already been rebased.
- Single-layer rendering avoids unnecessary composition and retains exact RGBA.
  Native Save finds edited ranges through binary search in sorted IDs rather
  than scanning all edited IDs for every sheet.

## Ownership, memory and compatibility observations

The application is ActionScript/AIR with a managed C# helper, not a C++ codebase.
C++ smart pointers are therefore not the applicable remedy. Managed references
still require explicit lifetime control for bitmaps, byte buffers, native process
handles, streams, timers and subscriptions. The reviewed C# I/O paths use using;
native process listeners are removed before termination; previews are owned by
their caches and copied/cloned into the views rather than freed by borrowers.

Bounds remain: 16 queued jobs; 100-record pages; 8 MiB/64 decoded AS preview frames;
64 MiB decoded helper sheets; 64 MiB edited pixels; 32 MiB edited metadata;
bounded imports, pixel packets and protocol lines. Saved edit caches are released.
Unchanged DAT/SPR and Multi-SPR encoders were not replaced or broadly rewritten.

Public compatibility entry points, registered/reflection-based commands, parser
branches and utilities used by tests were not deleted merely because a textual
search found few callers. No speculative bulk dead-code or duplicate removal was
performed: breaking a runtime binding costs more than retaining a no-op API.
This audit fixes confirmed retention paths and redundant work, not guessed ones.

- New ReviewRegressionTests: outfit masks/base layers, atomic clear/rejection,
  helper recovery, clipboard buffer ownership, repeated save/three retained
  backups, retained-generation recovery, unrelated/hash-mismatched resources,
  malformed retention metadata and final notification failure.
- Existing synthetic save/import/wire/PNG tests, including 10,000 malformed wire

  project guards, settings, full queue rejection, dirty conversion completion,
  blocked Save As close, native Save/reopen and OBD/AEC; managed AS memory

  merge, strict RLE, rollback, 65,536 DAT items, stale/failed queues, 25 close
  cycles, progress layout, warning windows and dark Alert callbacks.
- Legacy UI against real 8.60 input: translated/scaled layouts, Save state,
  clipboard callbacks and cancellation of pending selection on reset.
- 10,000 real-source preview stress iterations: p50 0.0046 ms, p95 4.1399 ms;
  decoded sheet cache 66,650,112 bytes (below 64 MiB); helper working set
  298,590,208 bytes, private bytes 263,397,376, 271 handles, managed estimate
  155,155,584 bytes. These are one-run observations, not benchmark guarantees.

Tests wrote disposable D: fixtures; supplied game assets were only read.

## Limitations and follow-up

Inherited startup callback/binding diagnostics remain in the harness; they are
not represented as a zero-warning result. No running commercial Tibia client,
third-party Assets Editor GUI certification, native-runtime sanitizer run or
formal absence-of-leaks/UAF proof was performed. Ten thousand previews and close
cycles do not replace a long-duration allocation/handle profiler.

Locked or malformed retention inputs defer cleanup. Non-writer-format original
payloads, backups with unrecognized names and hash-mismatched files are retained
conservatively; no recursive cleanup of source/user directories is performed.
Removed expired writer backups are not recoverable through this tool, but the
three retained generations keep their referenced resources for recovery.
CodeRabbit CLI was not installed in this environment, so no local CodeRabbit
review is claimed; manual source review and the regression evidence above apply.
