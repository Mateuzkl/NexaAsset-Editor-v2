# Assets deste pacote

Os SVGs nas pastas `icons/default/` e `icons/active/` são ilustrações vetoriais simples geradas especificamente para este pacote, sem cópia de arquivos de bibliotecas externas. Podem ser usados, adaptados e redistribuídos no projeto NexaAsset Editor v2. Não há fontes de terceiros neste pacote.

As screenshots e a imagem conceitual de referência destinam-se a guiar implementação visual. **Não incorporar o mockup como tela estática do produto.** A imagem de referência pode conter arte de sprites e palavras ilustrativas: implemente componentes reais e carregue dados reais do editor.

Se o Codex optar por importar bibliotecas de ícones externas, deve documentar dependências e licenças correspondentes, preferindo as já instaladas no projeto.
